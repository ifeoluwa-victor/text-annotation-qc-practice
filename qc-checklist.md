# Quality-Control Checklist

I run these checks before calling a labelled file finished.

## Completeness
- [ ] Every text has exactly one label
- [ ] No label cells are blank
- [ ] No item ID appears twice

## Spelling and format
- [ ] Every label is spelled exactly as in the guidelines (DEFINITION, PROCEDURE, SAFETY, STUDY_CAREER, UNCLEAR)
- [ ] No extra spaces and no lower-case labels
- [ ] The file opens correctly as a table

## Accuracy against the guidelines
- [ ] I checked each label against the rules in `annotation-guidelines.md`
- [ ] Safety, radiation and wellbeing texts are labelled SAFETY (rule 2)
- [ ] UNCLEAR is used only when no other label fits
- [ ] Hard cases have a short note

## Consistency
- [ ] Similar texts have the same label
- [ ] I counted the labels and the total equals the number of texts (DEFINITION 9, PROCEDURE 5, SAFETY 7, STUDY_CAREER 6, UNCLEAR 3 = 30)

## Last step
- [ ] If I changed a rule, I updated the guidelines and re-checked the labels
