# Text Annotation QC Practice

A small project where I practise giving short texts consistent labels, following written guidelines, and checking my work with a quality-control checklist.

> **AI disclosure:** I used Claude (Anthropic) to help draft the guidelines and the starting set of labels. I review every label against the guidelines myself and change any I disagree with.
> **Data:** The 30 texts are synthetic questions written for practice. They are not real messages, and no real people or patients are involved.

## What this project shows
- Writing clear label definitions
- Handling unclear cases with simple rules
- Labelling consistently
- Checking work with a quality-control checklist

## Files
- `annotation-guidelines.md`: the labels, the rules, and how I handle unclear cases
- `annotated-sample.csv`: 30 short texts with their labels and notes
- `qc-checklist.md`: the checks I run before calling a file finished

## Status
All files are added. I reviewed the labels and guidelines as I built them.

## Limits
This is a small practice set. It is not a validated dataset.
